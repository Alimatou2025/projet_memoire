# Résoudre une équation à une inconnue

## Définition

Une équation à une inconnue est une égalité contenant une lettre (souvent x) dont on cherche la valeur qui rend l'égalité vraie.

## Les règles de base

1. **On peut ajouter ou soustraire le même nombre des deux côtés** de l'équation sans changer sa solution.
2. **On peut multiplier ou diviser les deux côtés par le même nombre non nul** sans changer sa solution.

## Méthode de résolution, étape par étape

Résoudre 3x + 5 = 20 :

1. On isole le terme avec x : on soustrait 5 des deux côtés → 3x = 20 − 5 = 15.
2. On divise les deux côtés par 3 → x = 15 / 3 = 5.
3. On vérifie : 3 × 5 + 5 = 15 + 5 = 20. ✓ C'est correct.

## Équation avec x des deux côtés

Résoudre 2x + 3 = x + 8 :

1. On regroupe les x d'un côté : on soustrait x des deux côtés → x + 3 = 8.
2. On isole x : on soustrait 3 des deux côtés → x = 5.

## Équation avec des fractions

Résoudre x/2 + 3 = 7 :

1. On isole le terme avec x : x/2 = 7 − 3 = 4.
2. On multiplie les deux côtés par 2 : x = 4 × 2 = 8.

## Problèmes concrets (mise en équation)

Pour un problème posé en français (ex : "un nombre augmenté de 5 donne 20"), il faut d'abord traduire la phrase en équation (x + 5 = 20), puis appliquer la méthode ci-dessus pour la résoudre.
