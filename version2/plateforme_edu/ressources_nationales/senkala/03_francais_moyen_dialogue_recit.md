# Décrire et insérer un dialogue dans un récit

## Objectifs

- Maîtriser les techniques de description textuelle.
- Comprendre les points de vue narratifs.
- Enrichir le vocabulaire de parole et des sensations.
- Transformer le discours direct en discours indirect.
- Intégrer dialogues et descriptions dans un récit.

## Les caractéristiques du texte descriptif

- Temps les plus utilisés : l'imparfait et le présent.
- Expansions du groupe nominal (adjectifs, appositions, propositions relatives).
- Champs lexicaux thématiques, vocabulaire de précision (formes, matières, couleurs), vocabulaire sensoriel.
- Organisation spatiale : indices spatiaux (haut/bas, gauche/droite), trois types de regards (panoramique, rapproché, gros plan), description statique ou dynamique.
- Présence du descripteur : modalisateurs, vocabulaire appréciatif, images (comparaisons, métaphores, personnifications).

## Points de vue narratifs

- **Omniscient** : le narrateur connaît tous les secrets des personnages.
- **Interne** : le narrateur est dans la peau d'un personnage.
- **Externe** : le narrateur observe sans interpréter.

## Transformer le discours direct en discours indirect

Changements à opérer : temps des verbes, pronoms, adjectifs possessifs, compléments temporels.

## Exemples de textes étudiés

- *Monsieur Ali* — description d'un pêcheur professionnel.
- *La maison natale* (Nafissatou Diallo) — description domestique.
- *L'enfant noir* (Camara Laye).
- *De la nuit au jour* (René Maran) — sensations auditives.
