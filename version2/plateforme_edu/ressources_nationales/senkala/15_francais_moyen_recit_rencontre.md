# Le texte narratif (Rencontre)

## Définition

Un texte narratif raconte une histoire réelle ou imaginaire. On le trouve principalement dans les romans, nouvelles et contes. Son but est de raconter, d'informer, de témoigner et de distraire.

## Le schéma narratif

Un récit suit généralement une structure chronologique en cinq étapes :

1. **Situation initiale** : le cadre, les personnages, avant que tout commence.
2. **Élément déclencheur** : ce qui vient perturber la situation initiale.
3. **Péripéties** : les actions, les complications qui s'enchaînent.
4. **Élément de résolution** : ce qui permet de dénouer la situation.
5. **Situation finale** : le dénouement, comment tout se termine.

## Le narrateur

Le narrateur peut raconter à la première personne (« je »), s'il est un personnage de l'histoire, ou à la troisième personne (« il », « elle »), s'il est extérieur à l'histoire.

## Le temps du récit

Le passé simple est le temps le plus utilisé dans un récit, mais pas le seul (l'imparfait sert souvent pour les descriptions et les actions qui durent).

## Les points de vue narratifs

- **Focalisation externe** : le lecteur n'a accès qu'à ce qui est visible, comme une caméra.
- **Focalisation interne** : le lecteur voit à travers les yeux d'un personnage.
- **Focalisation zéro** : le narrateur est omniscient, il connaît les pensées de tous les personnages.

## Techniques de construction du récit

- **Retour en arrière** (analepse) : revenir sur un événement passé.
- **Anticipation** (prolepse) : annoncer un événement futur.
- **Ellipse** : passer sous silence une partie de l'histoire.
