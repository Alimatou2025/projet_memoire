# Équations à deux inconnues de type ax + by + c = 0

## Objectif

Comprendre les équations et systèmes à deux inconnues, utilisés pour résoudre des problèmes en géométrie, physique et économie.

## 1. Vérifier qu'un couple est solution

Méthode : substituer les valeurs du couple dans l'équation pour vérifier si l'égalité est vraie ou fausse.

## 2. Trouver un couple solution

Attribuer une valeur arbitraire à une inconnue, puis résoudre l'équation à une seule inconnue obtenue.

## 3. Résolution graphique

Une équation de type ax + by + c = 0 est l'équation générale d'une droite. Tracer la droite permet de visualiser toutes les solutions.

## 4. Systèmes d'équations — trois méthodes

- **Substitution** : exprimer une inconnue en fonction de l'autre, puis remplacer.
- **Combinaison / élimination** : multiplier les équations pour obtenir des coefficients opposés, puis additionner.
- **Égalité / comparaison** : exprimer la même inconnue dans les deux équations et les égaliser.

## 5. Résolution de problèmes

Quatre étapes : choix des inconnues, mise en équations, résolution, interprétation des résultats.
